# NexoraOne

NexoraOne 是一个基于 Spring Boot 3、Vue 3 和 Uni-App 的前后端项目。

## 项目结构

- `nexora-one-api-java17-springboot3`：Java 17 后端服务
- `nexora-one-web-javascript`：Vue 3 管理端
- `nexora-one-app`：Uni-App 移动端
- `数据库SQL脚本/mysql/nexora_one_v3.sql`：MySQL 初始化脚本

## 命名约定

- 产品名称：`NexoraOne`
- Java 包名：`com.nexoraone`
- Maven 与 npm 模块：`nexora-one-*`
- JavaScript 标识：`nexoraOne*`
- 数据库与存储键：`nexora_one_*`

第三方组件保留其官方名称和坐标，例如 Sa-Token 与 smartdb。
